01 — 背景与目标

申请季的信息，散落在十几个地方

留学申请是一个持续 6–12 个月、涉及数十个任务的漫长项目。但申请者的信息却散落在学校官网、Excel、备忘录、邮件和微信收藏里。

问题：DDL 失控

不同学校、不同轮次的截止日期全靠脑记和表格，一旦遗漏就是整年的代价。

问题：文书版本混乱

PS、CV、推荐信各自迭代了 N 版，"最终版_v3_真的最终.docx"是常态。

问题：进度无感

"我到底准备到哪一步了？"缺乏全局视图，焦虑感远大于实际工作量。

目标用户

计划 1–2 年内申请海外硕士/本科的学生（18–28 岁），DIY 或半 DIY 申请，同时推进 5–10 所学校。他们是移动互联网原生用户，习惯高效率工具产品，对"信息密度"和"操作路径"敏感。

设计目标

3 秒任意关键信息（DDL / 文书状态 / 总进度）可达
1 屏首页一屏呈现今日重点，无需翻页找任务
0 学习成本遵循成熟大厂设计语言，开箱即会用

03 — 设计过程

从"混乱"到"秩序"的四步

3.1 用户研究：三个关键洞察

访谈了 6 名正在申请或刚完成申请的学生，并走查了 Notion 模板、Excel 表格和 3 款同类产品。三个反复出现的痛点直接塑造了产品形态：

① "我怕错过"

DDL 焦虑是最高频情绪。设计响应：首页「近期截止」列表 + 颜色分级圆点 + 今日聚焦卡。

② "我不想来回切"

在学校官网、文档、表格间反复跳转。设计响应：一切收拢进 5 个 Tab，关键操作 ≤ 2 步。

③ "我想看到进展"

漫长申请季需要正反馈。设计响应：百分比、阶段时间轴、勾选任务的正向动效。

3.4 视觉探索：为什么选"大厂风格"

探索了三个方向：年轻化渐变风、深色个性风、大厂工具风。最终选择后者——目标用户每天面对的是"不能出错"的任务，工具的确定感比个性更重要。字节/支付宝/飞书式的设计语言已被充分教育，零学习成本，能把用户的注意力完全留给内容。

被否决 · 渐变装饰风
玻璃拟态 + 多彩渐变 + 装饰球

视觉抢眼但稀释信息层级；状态色与装饰色互相干扰，DDL 警示不够"刺眼"。

最终采纳 · 大厂工具风
单品牌蓝 + 语义功能色 + 间距建立层级

颜色只承担"语义"：蓝=品牌/进行，绿=成功，橙=警告，红=错误。克制的视觉让状态自己说话。

3.5 关键设计决策

信息密度 ≠ 拥挤

首页承载 5 个模块但不显乱：用 Token 化的间距节奏（12/16/20/24）和字重梯度（Bold→Medium→Regular）替代分割线，让"留白"做信息分组。

状态驱动一切

每个元素先定义状态矩阵（默认/悬停/按下/禁用/加载/成功/错误）再谈样式。DDL 圆点用「逾期红 / 3 天橙 / 7 天蓝 / 更久灰」四级语义，3 秒内可扫读。

卡片不嵌套卡片

列表项直接放在一张白卡内用 1px 分隔线区隔（最后一项无分隔线），避免"盒中盒"带来的视觉噪音。

空状态必须给下一步

所有空态都不是"什么都没有"，而是「标题 + 引导文案 + 主按钮」——例如搜索无结果时提供「清空搜索条件」。

一致性如何保障

语义化命名

Token 按"用途"而非"长相"命名（--text-secondary 而非 #475569），换肤或 Dark Mode 时只需改映射层。

组件原子化

Button / Tag / Card / ListItem 全部有规格表：高度、内边距、圆角、各状态色值，禁止临时发明样式。

上线前检查清单

每次交付过一遍大厂风格检查清单（见下方），用规则代替感觉，保证多页面如一页。

所有间距来自 Token 系统，没有随机数值
所有颜色有语义定义，没有硬编码色值
每个可交互元素包含完整状态定义
卡片不嵌套卡片，列表末项无分隔线
空状态提供明确下一步操作
文字对比度满足 WCAG AA
图标来自同一套图标库（Lucide 线性）
按钮文案用"动词+名词"，不用"确定/取消"
状态标签颜色全产品语义一致
动效有明确时长与缓动规范

08 — 复盘与思考

挑战、取舍与下一步

挑战：密度与降噪的矛盾

问题：首页要塞 5 个模块，早期版本像"信息墙"，走查中用户找不到重点。

解决：确立"今日聚焦"为唯一视觉重心（唯一使用渐变底色的卡片），其余模块全部白卡降噪；用间距节奏代替边框分割。

挑战：悬浮按钮遮挡内容

问题：「AI 润色」悬浮胶囊随列表滚动，始终压住最后一张文书卡片。

解决：把它移出滚动容器改为相对屏幕固定定位，并给列表底部预留 72px 安全区——小改动，但建立了"悬浮层不随内容滚动"的规则。

取舍：单色蓝的"无聊"

取舍：放弃多彩装饰换来状态色的绝对辨识度。工具产品的"信任感"来自克制，用户的注意力应该留给自己的申请，而不是界面。

重来一次：会尽早补 Dark Mode 的 Token 语义层、增加首次使用引导，并接入真实院校数据做联调。
